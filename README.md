# Ironvault — Firearms Information Website

A modern and responsive firearms information website built using **HTML, CSS, JavaScript, and Tailwind CSS**. Ironvault presents firearm categories, specifications, historical information, and comparison features through an interactive and visually engaging interface.

## 🌐 Live Demo

[Visit Ironvault](https://zaheer457.github.io/Ironvault/)

## 📌 Project Overview

Ironvault is a frontend web development project designed to organize and present educational information about different types of firearms. It features a modern dark-themed interface with interactive sections that allow visitors to explore categories, view specifications, compare general attributes, and learn about firearm history.

The project demonstrates frontend development skills through responsive layouts, interactive components, JavaScript functionality, and modern UI design.

## ✨ Features

- **Modern User Interface:** Dark-themed design with an attractive visual layout.
- **Responsive Design:** Adaptable layout for desktop, tablet, and mobile devices.
- **Firearm Categories:** Organized sections for pistols, rifles, shotguns, submachine guns, and other categories.
- **Featured Information Cards:** Dedicated cards presenting selected firearms.
- **Specification Comparisons:** Interactive comparison sections with visual charts.
- **Historical Timeline:** Explore historical milestones related to firearms.
- **FAQ Section:** Expandable frequently asked questions.
- **Interactive Modals:** View additional information through detail popups.
- **Mobile Navigation:** Responsive navigation menu for smaller screens.
- **Newsletter Interface:** Frontend subscription form interaction.

## 🚀 Getting Started

No build tools or package installation are required.

1. Clone the repository:

   ```bash
   git clone https://github.com/zaheer457/Ironvault.git
   ```

2. Open the project folder:

   ```bash
   cd Ironvault
   ```

3. Open `index.html` in your browser.

You can also use the **Live Server** extension in Visual Studio Code for local development.

## 📝 Project Notes

- This is a frontend-only informational website.
- It does not currently include a backend or database.
- The newsletter form provides a frontend interaction and does not store or send subscriptions.
- Firearm information and comparison values are presented for general educational purposes.
